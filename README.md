# The Art of Memory

A research project on the art of memory — from the ancient techniques of places and images, through Frances Yates's *The Art of Memory* (1966), to modern learning-and-memory science — plus a growing collection of research on human optimization.

**Published site:** served from the repo root via GitHub Pages (`index.html`).

## Source discipline

Every factual claim in the report and page carries a source. Primary texts are marked **[Primary]**, scholarship **[Secondary]**. Quotations are reproduced only from passages actually read during research. Points where Yates's account is disputed are flagged **[Yates disputed]**.

## Open questions

- Historicity of the Simonides legend (the ancient sources themselves disagree).
- Bruno's wheels: magical system or combinatorial method? Genuinely disputed in current scholarship.
- Exact effect sizes for loci training come with the original authors' caveats (small samples, university populations).
